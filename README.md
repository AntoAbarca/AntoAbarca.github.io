# Portafolio || Fullstack 2

Este proyecto es un portafolio personal interactivo desarrollado con **React** y **Vite**. Incluye la presentación de un Currículum Vitae completo, enlaces de contacto directo, un formulario validado con React y soporte para cambio de tema (modo claro y oscuro).

## Características Principales

* **Perfil y CV:** Presentación de información básica, habilidades técnicas, educación y proyectos.
* **Enlaces Directos:** Acceso rápido a correo electrónico y perfil de GitHub.
* **Formulario de Contacto:** Sección dedicada con validación de campos mediante expresiones regulares (Regex) para garantizar datos válidos.
* **Modo Claro / Oscuro:** Alternancia dinámica de estilos visuales.
* **Diseño Responsivo:** Maquetación adaptable a dispositivos móviles y de escritorio.

## Tecnologías Utilizadas

* **Front-end:** React (JSX), Vite, JavaScript (ES6+), HTML5, CSS3.
* **Estilos:** Bootstrap 5 y CSS customizado.
* **Testing:** Vitest, React Testing Library y JSDOM.

## Pruebas (Tests)

El proyecto incluye una suite de **10 pruebas unitarias e integración** que verifican el correcto renderizado de componentes, manipulación del DOM, manejo de eventos y las validaciones del formulario.
